JavaScript Explorer Chrome Extension

🚀 Installation Instructions

Step 1: Load the Extension

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top right corner
  3. Click "Load unpacked" and select the extension directory
  4. The extension will appear in your extensions list

Step 2: Open DevTools

  1. Right-click on this page and select "Inspect" (or press F12)
  2. Look for the "JS Explorer" tab in the DevTools panel
  3. Click on the "JS Explorer" tab to open the extension

Step 3: Explore JavaScript Objects

  • Navigate the tree: Click on folders in the left pane to expand them
  • View properties: Select items to see their properties in the right pane
  • Use search: Type expressions like document.body in the search box
  • Context menu: Right-click on items for additional actions

✨ Features to Try

Address Bar Navigation

The address bar shows your current location and supports breadcrumb navigation:

Current Path: window.document.body

Auto-completion Search

Try typing these expressions in the search box:

window.loc
document.body.chil
testObject.nested
Array.prototype

Context Menu Actions

Right-click on any item in the tree to:

  • Inspect in Console - Logs the object to the browser console
  • Copy Path - Copies the JavaScript path to clipboard
  • View Source - Shows function source code
  • Highlight Element - Highlights DOM elements on the page

⚠️ Note

If you don't see the "JS Explorer" tab in DevTools, make sure:

  • The extension is properly loaded and enabled
  • You've refreshed this page after installing the extension
  • DevTools is fully loaded (try closing and reopening it)
